# MellstroyRNG
Одностраничный прототип мем-рулетки для GitHub + Netlify.

## Запуск локально
Откройте `index.html` в браузере или запустите любой локальный статический сервер.

## Публикация на Netlify
1. Загрузите все файлы проекта в новый GitHub-репозиторий.
2. В Netlify выберите **Add new site → Import an existing project**.
3. Подключите репозиторий.
4. Build command оставьте пустой, Publish directory укажите `.`.
5. Нажмите Deploy.

## Важно про TikTok
В проект добавлены официальные TikTok embed-ссылки. Встраивание, превью и запуск видео зависят от доступности TikTok, браузера и его autoplay-политики. Внешние TikTok iframe не дают сайту напрямую управлять их громкостью и гарантировать автозапуск. Чтобы сделать настоящее автоматическое воспроизведение центрального видео и общую регулировку звука, нужны сами видеофайлы (например MP4) или прямые разрешённые видеоисточники.

## Важно про аккаунты и рейтинг
Это frontend-прототип: гостевой ник и инвентарь сохраняются в localStorage текущего браузера. Случайный суффикс снижает вероятность совпадения, но не гарантирует глобальную уникальность между разными устройствами. Лидерборд пока локальный/демонстрационный. Для настоящей регистрации, общей базы инвентарей, уникальных ников и глобального лидерборда подключите Supabase или Firebase и серверную проверку выпадений.

## Настройки
Мемы, подписи и цены находятся в массиве `MEMES` в `app.js`.
